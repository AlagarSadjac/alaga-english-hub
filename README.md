## 📱 About The Project
Alaga English Learning Hub bridges language barriers by simplifying core English language concepts for Tamil native learners. It brings all essential learning modules together under a modern interface:
* 📖 **Grammar & Tenses Guide** (Detailed rules with contextual Tamil examples)
* 📝 **Daily Vocabulary Builder** (Essential spoken phrases & meanings)
* 🎯 **Dynamic Assessment Portal** (Real-time practice tests & automated scoring)

Engineered with a minimalist UI, quick asset loading, and complete mobile-first responsiveness.

---

## ✨ Features
* 🔐 **Secure Firebase Authentication:** Robust customer registration and login workflows powered by Firebase Auth.
* 📖 **Comprehensive Grammar Rules:** Detailed breakdowns of English tenses with simple, relatable Tamil explanations.
* 📝 **Tamil-to-English Vocabulary:** Frequently used daily vocabulary categorized for effortless memorization.
* 🎯 **100-Question Interactive Quiz:** Dynamic quiz framework providing instant score calculations and answers.
* 📱 **Modern Responsive Design:** Gradient-styled, lightweight user interface optimized across smartphones, tablets, and desktops.

## 🛠️ Built With

## 🚀 How To Run Locally

1. Clone the repository:
   git clone https://github.com/AlagarSadjac/alaga-english-hub.git

2. Navigate to the project directory:
   cd alaga-english-hub/public

3. Launch the web application:
   Double-click index.html to open directly in any web browser, or serve it using the VS Code Live Server extension.
