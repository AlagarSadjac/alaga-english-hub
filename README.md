# 📚 Alaga English Learning Hub

An interactive, responsive, and lightweight web application designed to help Tamil speakers learn English grammar, vocabulary, and test their skills with practice quizzes.

🔗 **Live Demo:** [Alaga English Learning Hub](https://alaga-english-hub-web.onrender.com) *(உங்கள் Render வெப்சைட் URL-ஐ இங்கே மாற்றுங்கள்)*

---

## ✨ Features

- 🔐 **Firebase Authentication:** Secure User Sign-Up and Login using Firebase Auth (Email/Password).
- 📖 **Grammar & Tenses:** Comprehensive English tense rules explained clearly with Tamil meanings and examples.
- 📝 **Vocabulary Builder:** Essential daily English words translated into Tamil for quick memorization.
- 🎯 **Interactive 100-Question Quiz:** Instant feedback and scoring for practice questions.
- 📱 **Fully Responsive UI:** Clean, mobile-friendly design built with modern CSS and gradient aesthetics.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Authentication:** Google Firebase Authentication
- **Deployment / Hosting:** Render (Static Web Service)
- **Version Control:** Git & GitHub
