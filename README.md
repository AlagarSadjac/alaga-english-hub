## 📱 About The App
This app provides a focused and structured mobile learning environment to learn English with Tamil explanations in one place, featuring:
* 📖 **English Grammar & Tenses**
* 📝 **Daily Tamil-to-English Vocabulary**
* 🎯 **Interactive 100-Question Practice Quiz**

Engineered with a minimalist UI, smooth performance, and an intuitive user-friendly design.

---

## ✨ Features
* 📖 **Grammar with Tamil Meanings:** Clear explanations of all English tenses with simple real-life examples.
* 📝 **Essential Vocabulary:** Curated daily-use vocabulary words translated into Tamil for quick memorization.
* 🎯 **Interactive Quiz:** Practice 100 interactive questions with immediate answer feedback and score calculation.
* ⚡ **Fast & Lightweight:** Optimized layouts and components for instantaneous loading and seamless navigation.
* 📱 **Clean UI:** Clutter-free interface focused on an engaging and distraction-free learning experience.

---

## 🛠️ Built With
* **Language:** Java
* **IDE:** Android Studio
* **Layouts:** XML Layouts & ConstraintLayout
* **Components:** Android Architecture Components & ViewBinding
* **Version Control:** Git & GitHub

## 🚀 How To Use
1. Download and install the APK using the download button above.
2. Open the app and choose from Grammar, Vocabulary, or Quiz sections.
3. Learn the rules, memorize words, and take tests to improve your English fluency 📚.

---

## 🎯 Purpose
The primary objective of this application is to deliver an accessible, distraction-free native mobile portal for Tamil speakers to comfortably practice and improve English communication skills anytime, anywhere.
