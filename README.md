## 💻 About The Platform
This responsive web platform delivers a structured online learning environment with Tamil explanations, featuring:
* 📖 English Grammar & Tenses
* 📝 Daily Tamil-to-English Vocabulary
* 🔐 Secure Firebase User Authentication (Signup & Login)
* 🎯 Interactive Self-Assessment Quizzes

Designed with modern CSS animations, mobile-first responsiveness, and clean UI for a distraction-free learning experience.

---

## ✨ Features
* 🔐 User Authentication: Email and password login/signup powered by Firebase Authentication.
* 📖 Grammar with Tamil Meanings: Clear, structured explanations of English tenses with easy examples.
* 📝 Essential Vocabulary: Curated daily-use vocabulary words with accurate Tamil meanings.
* 📱 Fully Responsive: Looks and works great on mobile phones, tablets, and desktop browsers.
* ⚡ Fast & Lightweight: Built using pure Vanilla JavaScript without heavy frontend frameworks.

---

## 🛠️ Built With
* Editor: Visual Studio Code (VS Code)
* Frontend: HTML5, CSS3, JavaScript (Vanilla JS)
* Authentication: Firebase Authentication
* Deployment & Hosting: Render (Web Service)
* Version Control: Git & GitHub

## 🚀 How To Run Locally

1. Clone the repository:
   git clone https://github.com/AlagarSadjac/alaga-english-hub.git
   cd alaga-english-hub

2. Open in VS Code:
   code .

3. Launch the project:
   Open index.html using the Live Server extension or directly in any web browser.

## 🎯 Purpose
The primary objective of this web application is to provide an accessible, free online learning portal for Tamil speakers to comfortably improve their English communication and grammar skills from any device.
